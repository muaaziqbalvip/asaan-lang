Asaan Lang kya hai?

Asaan Lang ek educational interpreter hai: likho print karta hai, agar/warna faisla, har loops, kaam functions, lists, dictionaries, aur safha/unwan/card se HTML website. Errors Roman-Urdu mein aate hain. Install ke baad command asaan Python ki tarah chalti hai.

naam = lo "Aap ka naam? "
agar naam != "" to
    likho "Khush Amdeed, " + naam + "!"
warna
    likho "Mehman, salaam!"
bas

Install

git clone https://github.com/muaaziqbalvip/asaan-lang.git
cd asaan-lang
./install.sh          # Windows: install.bat
asaan -e "likho \"Salaam Mizanora!\""
asaan --web examples/website.asaan -o site.html
